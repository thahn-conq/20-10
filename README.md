# 💖 20/10 Vietnamese Women's Day Interactive Greeting Card

> An enchanting, responsive digital greeting card celebrating Vietnamese Women's Day (October 20th), crafted with smooth CSS3 animations, animated SVG text paths, lovely typewriter effects, and soothing background music.

---

## ✨ Features

- **💌 Interactive Floating Envelope**: An animated 3D envelope with flying hearts and gentle floating effects that unfolds upon click.
- **✨ Animated SVG Heart Text**: Dynamic SVG path animation outlining a glowing heart with running greeting text.
- **📜 Romantic Typewriter Letter**: A customizable letter modal with a delicate typewriter typing animation, cursive typography, and cute animated GIF stickers.
- **🎵 Seamless Background Music (BGM)**: Soft melody that auto-plays with a smooth fade-in effect upon opening the letter, complete with a floating vinyl toggle button.
- **📱 Fully Responsive Design**: Pixel-perfect layout tailored for both Desktop monitors and Mobile screens with zero text overlapping or horizontal overflow.
- **🌸 Falling Petals & Glow Particle Effects**: Lightweight, floating petals and sparkling star background for a dreamy atmosphere.
- **⚡ Preloader & Offline Detector**: Elegant loading screen and real-time offline network notification toasts.

---

## 🛠️ Built With

- **HTML5 & Semantic Markup**
- **Vanilla CSS3** (Keyframe animations, Flexbox, Responsive Media Queries)
- **JavaScript (ES6+) & jQuery** (SVG Path Manipulation, Typewriter Engine, Web Audio API)
- **Google Fonts** (*Dancing Script*, *Great Vibes*)
- **FontAwesome 6** (Icons)

---

Simply open `index.html` in any modern web browser:

```bash
# Double click index.html or serve locally
```
